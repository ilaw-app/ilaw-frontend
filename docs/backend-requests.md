# 프론트엔드 → 백엔드 요청 사항

> 프론트(airo-web)에서 현재 우회책으로 동작하지만, 아래를 지원해주면 **네트워크 요청 수와 응답 시간이 크게 줄어듭니다.** 기능이 막혀 있는 건 아니고 성능 개선용입니다.

## 🟡 1. Q&A 목록 응답에 대표 이미지 포함
- **엔드포인트**: `GET /qna` (목록)
- **요청**: 각 항목에 `imageUrls`(또는 대표 썸네일 URL 하나)를 포함해 주세요.
- **이유/현재 상태**: 목록에 썸네일을 보여주려고 프론트가 **질문 하나하나 상세(`GET /qna/:id`)를 추가로 조회**하고 있습니다. 목록이 40개면 마운트 시 41개 요청이 나갑니다.
- **해결 시**: 이 N+1 조회를 제거할 수 있습니다.
- 참고: `src/routes/QnaList.tsx` 의 썸네일 보강 로직(`// TODO(BE)` 주석).

## 🟡 2. 내가 쓴 커뮤니티 글 목록 엔드포인트
- **엔드포인트(신규)**: `GET /community/my-posts` — 로그인 사용자가 작성한 글만 반환 (기존 목록과 동일한 형태)
- **이유/현재 상태**: 커뮤니티 글 작성자가 `익명1`처럼 **익명화**되어 목록만으로는 내 글을 못 가립니다. 그래서 프론트가 **글마다 상세를 조회해 `isAuthor`로 판별**합니다(최대 60개 요청).
- **해결 시**: 마이페이지 "내 커뮤니티 글" 화면이 요청 1번으로 끝납니다.
- 참고: `src/routes/MyCommunityPosts.tsx`, `src/api/community.ts`(현재 `my-bookmarks`만 있고 `my-posts` 없음).

## ✅ 이미 반영/불필요 (요청 안 해도 됨)
- **커뮤니티 신고·블라인드**: BE 완료됨 (`POST /community/:id/report`, `/comments/:commentId/report`, 댓글 `status` 마스킹). 프론트도 안내문 감지해 표시하도록 맞춤.
- **AI 상황진단 계약**(agency/hotline suggestion, `crisis` status, history 5): 프론트와 이미 일치.
- **변호사 답변 데이터**: 우리가 의도적으로 넣은 프론트 정적 데이터라 요청 불필요.
